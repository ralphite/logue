## 三、缺了,我建议不补(理由在后面)

- **每个标签页一个面板文档**(`sidepanel.html?tabId=N`)—— v1 给每个标签页独立的草稿状态。
  今天一个面板跟着当前标签页走。**多一份状态就多一份能对不上的东西**,而这个产品是单人本地的;
  除非你真的会同时在两个标签页里各起一段草稿。
- **Host 地址 + 6 位配对码的设置面**(Host address / pairing code / Use detected Host)——
  M1 之后一台机器只有一个 Host、一个地址,这套 UI 是为"可能连到别的机器"准备的,现在没有那个场景。
- **麦克风权限的弹窗中转页**(`microphone.html`,360×180)—— 今天的录音走 offscreen 文档,
  权限属于扩展自己,这一层不需要了。
- **generate 模式的 Sources 勾选与置顶** —— v1 让你在跑之前勾哪些 Source、把某条置顶。
  今天 agent 自己找 Source 并把找了什么、找到几条**列出来**。
  真要控制,我建议做成"对这次回答换一批 Source",而不是把 v1 那套勾选盘搬回来。
- **auto-run token** —— v1 支持"打开面板就自动跑一次生成"。⌘⇧K 已经覆盖了它的用处。

## 四、这里面有一个真 bug,不是缺功能

**P5 的后半句**:面板里现在的 Esc/Enter 监听挂在 `window` 上,**没有排除输入框**。
在 ask 输入框里打字时按 Esc,会取消正在进行的录音;按 Enter 也会抢在换行之前采纳。
v1 有一整个 `isEditableTarget` 守卫(输入框、textarea、select、contenteditable、
IME 组字中、按键重复、任何修饰键)。这条我建议**不等你拍板就修** —— 它属于"现在就是坏的"。
