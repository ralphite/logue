# N4 · 面板里的 Dictation

面板加一个 **Dictation** tab:能录音、音频和文字都在、一键复制、用预定义的 Skill 一键改写、
前一条还在转写时能接着录下一条。录的时候把当前页面的可见文字一起当 context。

**能点的 mockup:** `scratchpad/dictation-v4.html`(左边那块是活的)。

---

## 一、整个界面只有四个动作

**录**、**播**、**复制**、**套一个 Skill**。屏幕上没有第五样东西。

## 二、录音控件:一个,在底部,原地变形

- 平时:`[🎤 Record]` —— 一个按钮,旁边什么都没有。
- 按下之后**同一个框**变成:`✕ · ● 计时 · 波形 · ✓`。手不移动,眼睛不换地方。
- **Esc 取消,Enter 完成** —— 和光标旁那条浮层同一套键。

## 三、每一段文字长得一样

转写和它生出来的每一版,都是同一个东西:**一段文字,底下一排 `复制 + 还没用过的 Skill`**。
没有"原文块 / 改写块"两种样式。

- **每一段都能再套 Skill**,想套几层套几层。
- **缩进就是 lineage**:缩在谁下面就是从谁来的。回到最上面那段再套一个,新的一版和它的兄弟并排。
- **用过的 Skill 不再出现在那一段上**(按 text 算,不是按整条录音)。
- **没有关闭,没有删除。**

## 四、播放器:一个控件,一个时间

`▶ · 波形 · 0:47`。空闲显示总长,播放时显示播到哪 —— 任何时候只有一个数字。波形能点,点哪跳哪。
浏览器原生 `<audio controls>` 换掉。**这个组件面板和 Web 应用共用,两边一起变。**

## 五、明确不做的

| | 为什么 |
|---|---|
| 语音选项(Project / Language / Vocabulary) | Settings 里已经有,面板里再放一份是两个真相 |
| "还有 n 段在转"的计数 | 那一段自己就在列表里转着,不用再数一遍 |
| "10:00 自动停"的提示 | 不要 |
| 版本编号(v1 / v2 ← v1) | 缩进已经说清楚 lineage,编号是第二套说法 |
| 关闭 / 删除一个版本 | 版本不是弹窗 |
| ↶ Undo | 面板里没有光标,没有东西可以撤回 |
| ✨ Ask Logue | 那是 Chat 那个 tab 的事 |

## 六、其余的

- **一行 = 一段录音**:转写中 → 播放器 + 文字 → 底下长出版本。
- **最新的录音在最上面。**
- **改写点下去,位置先占住**:按钮转圈,同一刻下面出现新版本的位置,文字到了填进去。
- **麦克风只有一个**,同时只录一段;按下 ✓ 那一刻就还回来了,下一条马上能开(V3 已经成立)。
- **出事写在出事的那一行。**
- **页面可见文字随录音一起送过去**,进现有的转写上下文通道。

## 八、一件顺手做掉的

查"页面可见文字怎么取"时撞到的 bug,**和 Dictation 无关,但影响它**:
`readablePageText()` 靠"含空格"判断正文,中文句子没有空格。真实中文维基页上 440 块丢掉 362 块,
正文段落全丢 —— 存下来的中文页面一直只有一半。已修:中文页 87→169 块,英文页 699→699 零变化。
