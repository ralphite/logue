# Product design references

These screenshots are durable visual references for Logue UI reviews. They were captured from the signed-in production apps on 2026-08-02 and must stay in the repository instead of a temporary directory.

## Sources

- `notion/`: [Notion](https://app.notion.com/) pages, side peeks, Skills, and Settings.
- `chatgpt/`: [ChatGPT](https://chatgpt.com/) home and navigation.

## What to compare

- Quiet, content-first hierarchy with no success-state noise.
- Stable content axes and consistent spacing across pages.
- Progressive disclosure instead of permanent explanatory copy.
- Predictable split-panel sizing with useful space on both sides.
- Readable typography, generous hit targets, and restrained selected states.

These references guide visual quality and interaction principles; Logue should not copy product branding or unrelated controls.
