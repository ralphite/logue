## 端到端证据

- 最新 Chrome 构建完成一次“使用并保存”后同步插入网页与落库；没有第二次确认，也没有提交宿主表单。
- 最新 Chrome 构建完成真实右键选区 → 独立批注保存；`selection` 原文与 `derived` 批注通过父资料关联。
- 最新 Chrome 构建覆盖转写失败保留录音、页面切换导致目标丢失后先落库、重新聚焦后幂等插入，以及服务断开后轮询自动恢复。
- 真实 Gemini 音频在当前服务构建再次转写并落库；机器转写与人工调整后的最终采用文本内容不同，原始音频仍由同一 `capture_id` 关联。
- 保存选区产生不可变 `selection` 原文与独立 `derived` 批注，父子关系可回溯。
- 三组真实 Gemini 音频覆盖英文、长中文和中英专有词；结果、转写和原始音频均保留。
- 原始音频由浏览器加载元数据，并用 `ffprobe` 验证 9 个保存文件均含可解码音频流。
- Agent 资料包只读；写回缺少 `actor`、缺少 `source_ids` 或引用不存在的资料都会返回 400；合法写回保留 actor 与父来源；同一稳定 `request_id` 重试仅产生一条资料。
- 在隔离副本中执行导出恢复后重启，资料、成果、项目和音频计数保持一致，且恢复前创建自动备份。
- 行内 `[来源 n]` 与右侧 `#n` 稳定对应；删除未被正文使用的早期来源会同步重排后续编号，删除仍被正文引用的来源会被阻止并给出修正提示。
- `/v1/context` 返回最近 5 条用户最终采用表达；扩展把它们作为“只用于保持用词和语气一致”的转写上下文发送。
