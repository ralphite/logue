# Logue 核心交互规格

## 语音输入：极简直接插入

最新用户纠正覆盖旧的“停止后审阅”流程。正确默认流程为：

`聚焦输入框 → 麦克风出现 → 点击录音 → 停止并插入 / 取消`

- 录音态主动作：`停止并插入`；自动转写、保存、插入。
- 录音态唯一次动作：`取消`；立即丢弃本次未采用录音。
- 不存在审阅页、重录、项目、Tag、参考详情或归档选择。
- 快捷键直接开始录音；录音中再次触发快捷键等同“停止并插入”。
- 保存完成前不得写入宿主输入框。
- 插入只分发宿主 `input` / `change` 所需事件，不按 Enter、不提交表单。
- 连续点击由提交锁阻止；网络响应丢失时稳定 `request_id` 保证幂等。

## Extension 状态机

| 状态 | 主动作 | 次动作 | 完成/恢复 |
| --- | --- | --- | --- |
| `idle` | 开始语音 | 无 | 只在当前输入框聚焦时显示入口 |
| `recording` | 停止并插入 | 取消 | 停止进入自动处理；取消丢弃内存音频 |
| `processing` | 无 | 无 | 自动转写、保存并插入；失败进入错误 |
| `committing` | 禁用重复提交 | 无 | 成功关闭；失败进入错误 |
| `error: transcription` | 重试并插入 | 取消 | 保留录音，不增加审阅步骤 |
| `error: microphone` | 再次录音 | 取消 | 不阻断原网页输入 |
| `error: save` | 重新保存 | 取消 | 宿主页面保持未写入 |
| `error: target` | 重新聚焦后插入 | 复制文字 | 资料已经安全保存 |
| `disconnected` | 自动重连后恢复 | 关闭 | 面板打开时每 2 秒检查一次本机服务 |

关闭尚未采用的录音会删除对应 capture；已经绑定到资料的录音不会被面板关闭删除。

## 输入框模式

- 入口只在真实可编辑目标聚焦时出现，不覆盖宿主关键控件。
- 输入主流程不展示页面、项目、Tag、参考或 Context；这些由后台自动使用或在资料保存后整理。
- 快捷键必须和点击入口产生完全相同的开始/停止行为。
- 目标在提交前被移除时，先保存的资料仍保留，并提供重新插入或复制。
- 成功反馈为 `已插入网页并保存到资料流`，2.6 秒后自动消失。

## 选区模式

- 右键菜单名称：`保存到 Logue`。
- 完整选区只读展示；过长时视觉截断，但保存内容不得截断。
- 批注输入为空：`保存选区`。
- 批注输入非空或存在语音转写：`保存原文与批注`。
- 原文与批注永远是两条资料，批注通过 `parent_ids` 指向原文。

## Web App

### 资料流

- 初始只展示列表，不自动打开第一条详情。
- 搜索同时覆盖内容、来源、项目与标签。
- 筛选保留 `全部 / 需要确认 / 未归项目 / 已归项目`；“需要确认”只来自后台低置信度或异常结果，不是所有输入的待办箱。
- 点击资料打开右侧详情；窄屏时详情覆盖主列表。
- 新资料保存后后台自动归项目与 Tag；高置信度时安静完成，低置信度在列表和详情显示“需要确认”。
- 任何资料内容可进入编辑并保存；项目归属使用直接点选并立即保存，标签按 Enter 添加并立即保存。用户修改项目或 Tag 即确认该组织结果。

### 项目

- 项目列表展示名称、概览摘录、资料数和文档数。
- 项目详情的概览与术语自动保存；保存状态始终可见。
- Gemini 概览草稿必须显式“追加到概览”，不能自动覆盖。
- 项目资料和文档都可直接打开对应一级页面。

### 生成

- 一级名称为“生成”，不使用“成果”。默认先展示最近生成和“新生成”，不自动打开一个空白文档。
- 新生成的最小输入是 `Agent + 本次要做什么`；项目和资料作为可检查、可更改的上下文，默认由当前位置与 Agent 规则装配。
- 生成结果根据 Agent 形态显示：短回复/消息为可编辑文本和复制/插入动作；QA 为问答对；文档进入持续编辑器。
- 生成历史保留 Agent 名称/版本、来源和结果；用户修改结果不改写原始资料。

### Agent

- 用户可新建、复制、重命名、启用/停用和编辑 Agent；默认 Agent 不可无恢复地被覆写。
- Agent 编辑采用与项目/文档相同的内容优先、自动保存模式：标题、目的和指令在主内容区，任务类型、输出形态、上下文和可用表面使用紧凑设置。
- 转写 Agent 只控制听写规则；整理 Agent 只能从实际项目白名单中选择并输出结构化 Tag/置信度；生成 Agent 必须记录实际来源。
- 不在第一版暴露 MCP 权限编辑器或模型细节矩阵；这些只在真实工具调用出现时渐进展开。

### 文档结果

- 左侧文档列表 + 中间可编辑文档 + 可开关来源面板。
- 标题是页面第一视觉层级；项目、来源数与更新时间位于标题下方。
- 已引用来源与可添加来源不重复出现；已引用用品牌紫表示，绿色只表示连接/保存成功。
- 行内 `[来源 n]` 与右侧 `#n` 一一对应；点击行内引用会打开来源面板、滚动并高亮对应资料。
- 添加引用默认只搜索当前项目；用户可显式切换到“全部资料”，避免跨项目作用域含混。
- 来源行展示唯一标题、项目/域名/日期；原始 URL 使用独立外链动作。
- Markdown 标题、列表、粗体、代码与 `[来源 n]` 在编辑器中正确呈现。

## Extension Agent 生成

- 当真实输入框聚焦时，除麦克风外可显示独立“生成”入口；两者图标和快捷键语义必须不同。
- 点击生成后，默认运行用户设定的 Extension 默认 Agent；需切换时才展开 Agent 列表，不每次强迫选择。
- 可使用当前输入框内容、当前页面、显式选区与自动关联的单一项目/资料；实际使用项必须随运行记录。
- 返回结果在小面板内可编辑，主动作为“插入”；不自动发送、不按 Enter。

## 键盘与可访问性

- `Escape` 在非录音状态关闭 Extension 面板，关闭后焦点返回原输入框。
- 图标按钮必须有可读名称、至少 32px 点击区域、hover 与键盘焦点态。
- 颜色不是唯一状态信号；连接、录音、保存和错误同时显示文字。
- 支持 `prefers-reduced-motion`；波形和加载动画在降低动态效果时停止。
